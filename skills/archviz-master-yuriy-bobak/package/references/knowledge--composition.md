# Composition
Composition arranges visual elements to create a clear read and direct attention.

## Principles
- Establish a focal point early.
- Design primary, secondary and tertiary reads.
- Judge large shapes before detail.
- Use negative space deliberately.
- Balance visual weight, not merely symmetry.
- Shape, scale, proximity, rhythm, movement, perspective, texture, value, color and light are compositional controls.
- Rule of thirds, golden ratio and Fibonacci structures are tools, not mandatory formulas.
- Leading lines should support the subject rather than lead the eye out.
- Repetition creates rhythm; variation avoids mechanical repetition.
- Overlap can create depth; avoid ambiguous tangencies.
- Rules can be intentionally broken when hierarchy and intent remain controlled.

## ArchViz checks
Is architecture the intended first read? Do roads, curbs, facade lines, landscape and shadows guide attention appropriately? Does the image work at thumbnail size? Can it be reduced to a few strong shapes and value groups?


## Expanded book-grounded diagnosis

Source keys L, C and P and page-number conventions are defined in the [evidence register](book-evidence-register.md). ArchViz applications are production interpretations, not software instructions from the books.

### Compose projected masses rather than the object list

C 317, 478 and 689 shows visual grouping that crosses object boundaries. A tree, barn and foreground can form one dark shape; unrelated physical objects can read as one light group.

**ArchViz application:** evaluate the camera image, not merely whether each object is individually attractive. Move a planting cluster or adjust its contrast when its projected silhouette unintentionally merges with the entrance.

### A scene can offer an entrance, a route and a destination

C 378-438 develops connected visual movement through shapes, framing and rhythm.

**ArchViz application:** check where the eye enters, how planting, paving or shadows carry it, and where it settles. These are optional design tools: an axial facade, quiet courtyard or centered product view need not imitate a winding landscape composition.

### Tangency fixes should be small and intentional

C 535 uses a targeted change to clarify a troublesome relationship; C 538 relates completion to communication rather than exhaustive detail.

**ArchViz application:** test a crop or small camera/object adjustment before redesigning the scene. A canopy touching a roofline or a trunk aligned with a column may require only a modest correction.
