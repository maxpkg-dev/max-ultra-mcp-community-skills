# RailClone A2S

A2S creates two-dimensional arrays from numeric dimensions and/or spline controls and can handle complex curved construction.

## ArchViz uses
- facades;
- curtain walls;
- cladding;
- panels;
- floors;
- ceilings;
- paving;
- tiles;
- structural grids.

A useful mental model is a stack of 1D arrays with row logic.

## Workflow
Define modular segment kit → define X/Y control → assign default/edge/corner/evenly/special segments → expose dimensions → add operators/conditions/randomization only where design logic allows → test revision behavior.

## Version scope
Inherited software notes; only the selected claims in [compatibility and validation](compatibility-and-validation.md) were rechecked during v1.2 adaptation.
