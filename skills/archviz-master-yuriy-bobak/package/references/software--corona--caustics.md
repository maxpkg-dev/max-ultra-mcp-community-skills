# Corona Caustics

Corona's caustics solver supports reflective/refractive effects, dispersion, motion blur, dedicated render elements, LightMix interaction and controls for surface/volume caustic contribution.

## Constraints
Refractive caustics require material support/enabling. Corona Lights are the supported light source for the caustics solver rather than native Max lights.

## Animation
Caustic noise patterns can vary frame to frame; animation may require substantial convergence to avoid flicker. Use only where caustics materially improve the shot.
