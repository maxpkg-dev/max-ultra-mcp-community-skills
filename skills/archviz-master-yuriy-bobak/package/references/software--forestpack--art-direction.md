# ForestPack Art Direction

ForestPack is not a 'random vegetation' button. Use distribution, areas, transforms, item editing, maps and effects to art-direct hierarchy.

## Naturalism checklist
- plausible species mix;
- plausible scale ranges;
- non-uniform density;
- clustering;
- orientation variation;
- terrain/slope suitability;
- designed clear zones;
- foreground framing;
- reduced background visual frequency;
- no obvious repetition.

## Items Editor
Use individual editing for hero-camera corrections without abandoning efficient scatter logic.

## Animation
ForestPack can scatter animated objects efficiently and supports synchronized/randomized timing approaches. Use for crowds, moving assets or animated vegetation only when it serves the shot.
