# Official Software Research — September 2026

Version target confirmed by user: 3ds Max 2027 family.

## Autodesk
Current 2027 documentation confirms Smart Bevel, custom-direction Extrude, Spline Chamfer updates, Noise Plus, Boolean improvements, Field Helper, OCIO updates and USD improvements. 2027.2 adds 3D Gaussian Splat support, Point object/modifiers and Point Instance true render-time instancing.

## ForestPack
Official documentation maps the Forest plugin into Geometry, Distribution, Areas, Surface, Transform, Items Editor, Camera, Material, Effects, Animation, Shadows, Display and General systems. Distribution includes Image, Path, Reference and PFlow. Camera visibility can cull unseen items. Areas include spline/object/forest/paint/surface workflows.

## RailClone
Official docs define Segments as building blocks, L1S for 1D spline arrays, A2S for 2D arrays, Operators for graph behavior and Macros for reusable compound graph logic.

## Integration
ForestPack 9.4.1 introduced RailClone segment distribution integration and requires RailClone 7.3.2+.
