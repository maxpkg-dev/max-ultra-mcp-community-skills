# Source Layer

Primary artistic sources are the three supplied Artists' Master Series books: Color and Light, Composition & Narrative, and Perspective and Depth. This package contains transformed principles and workflows, not copied books.

Read the [evidence register](book-evidence-register.md) for coverage and source keys, [extraction status](sources--extraction-status.md) for current limits, and [painting-to-CG boundaries](painting-to-cg-boundaries.md) for narrow external optics cross-checks.

Distinguish book observations, production interpretations, and version-sensitive software claims. Do not treat the package as an exhaustive replacement for the books.
