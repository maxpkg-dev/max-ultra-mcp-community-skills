# Visual Problem → Implementation Map
Weak focal hierarchy → first fix camera/composition/value/light; only then post.
Flat depth → overlap/scale/camera/contrast/saturation/detail hierarchy; atmosphere only if justified.
Flat facade → improve light direction, plane separation and reflection context.
Distracting background → reduce contrast/saturation/detail/texture frequency or restructure composition.
Unconvincing glass → inspect view angle, Fresnel/reflection, roughness, interior/environment content.
Over-detailed image → simplify secondary/background textures and entourage.
Distorted architecture → inspect camera distance, focal length, eye level, tilt and vertical correction.
Weak material realism → correct scale and physical response before adding dirt/imperfections.
