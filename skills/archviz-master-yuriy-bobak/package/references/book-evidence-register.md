## Evidence layers

1. Book observations: artistic principles and examples with page locators in the eight knowledge modules, [visual case studies](book-case-studies.md), and [mood evidence](mood-evidence.md).
2. Production interpretation: ArchViz diagnostic tests, ForestPack/RailClone applications, mood briefs and checklists synthesized from those observations. Proposed tests were not executed in a 3D scene during development.
3. Technical cross-checks: the PBRT references in [painting-to-CG boundaries](painting-to-cg-boundaries.md) qualify selected optics simplifications.
4. Preserved software knowledge: existing 3ds Max 2027, Corona, ForestPack and RailClone material. Most vendor versions, UI paths and compatibility remain unverified; see the limited [v1.2 documentation checks](compatibility-and-validation.md).

Source books are attribution, not required runtime assets. For a new page-specific quotation or illustration analysis, obtain and inspect the source; do not reconstruct unseen content from this summary.
