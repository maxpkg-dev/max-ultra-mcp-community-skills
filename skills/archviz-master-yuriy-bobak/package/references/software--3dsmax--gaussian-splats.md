# 3ds Max 2027.2 — Gaussian Splats / Point Workflows

3ds Max 2027.2 adds native 3D Gaussian Splat support plus a Point object/modifier workflow and Point Instance modifier.

## ArchViz opportunities
- captured site/context reference;
- survey/scan context;
- fast background/environment reconstruction;
- point-driven instancing for complex scenes.

## Caution
Treat splats as captured visual data, not automatically as clean architectural geometry. Validate scale, coordinate system, occlusion, editability and renderer compatibility for the target deliverable.

## Version scope
Inherited software notes; only the selected claims in [compatibility and validation](compatibility-and-validation.md) were rechecked during v1.2 adaptation. Confirm version-specific features, compatibility, UI paths and numeric settings against official documentation matching the installed version before use.
