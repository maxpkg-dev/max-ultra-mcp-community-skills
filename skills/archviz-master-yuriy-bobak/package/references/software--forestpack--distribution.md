# ForestPack Distribution

ForestPack's Forest plugin exposes distribution workflows including Image, Path, Reference and PFlow modes.

## Image mode
Use for area scattering such as grass, planting beds, forests, rocks and irregular environmental coverage.

## Path mode
Use regular/controlled placement along splines: trees along streets, bollards, lights, posts and similar linear layouts.

## Reference mode
Use explicit markers/references when exact locations matter. RailClone integration is exposed through Reference mode.

## PFlow
Use Particle Flow-driven placement when particle systems define positions.

## Decision
Area/natural field → Image.
Linear repeated path → Path.
Exact design coordinates/markers → Reference.
Particle-defined → PFlow.
Procedural RailClone placement → Reference + Use RailClone Items.
