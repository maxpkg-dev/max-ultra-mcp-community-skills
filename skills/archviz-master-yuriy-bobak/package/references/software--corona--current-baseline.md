# Corona Current Baseline — 2026 Research

Use official Chaos Help Center + indexed Chaos technical documentation as the open-web authority.

## Engine
Corona is CPU-based for rendering; compatible GPU hardware is optional for AI denoising. Interactive Rendering is intended for scene development rather than final rendering.

## Render Setup
Corona exposes Scene, Camera, Performance and System tabs in addition to native 3ds Max Common/Render Elements.

## Progressive limits
Production rendering can stop by Time, Pass, or Noise Level. If multiple limits are active, the first reached stops the render.

## Default-settings rule
Chaos guidance says default render settings are generally the best starting point. Do not prescribe a universal 'best settings' preset. Diagnose the scene/noise type first.

## Corona 15-era notes
- Old Corona Material Library toolbar workflow is removed; materials are in Chaos Cosmos.
- Corona Camera can override output resolution per camera.
- VFB 2.0 is the default VFB from Corona 12 onward.

## Version scope
Inherited software notes; only the selected claims in [compatibility and validation](compatibility-and-validation.md) were rechecked during v1.2 adaptation. Confirm version-specific features, compatibility, UI paths and numeric settings against official documentation matching the installed version before use.
