# ArchViz Production Decision Tree

## Repeated architectural geometry?
Yes → RailClone candidate.
Linear → L1S.
2D facade/floor/ceiling/paving → A2S.
Reusable graph logic → Macro.

## Dense natural/environment repetition?
Yes → ForestPack.
Area scatter → Image.
Along spline → Path.
Exact markers → Reference.
RailClone-driven → Reference + RailClone Items.

## Unique hero geometry?
Prefer native 3ds Max modeling/modifiers unless procedural reuse is expected.

## Visual problem?
Diagnose with ArchViz Core before software.
Composition → camera/object placement.
Depth → overlap/scale/atmosphere/detail hierarchy.
Light → source/environment/shadow design.
Material → physical response + scale + lighting context.
Performance → instances/proxies/scatter/culling/texture and scene audit.

## Final
Corona render/VFB/tone mapping should refine an already coherent scene, not compensate for unresolved composition.
