# Corona Open-Documentation Map

This skill deliberately uses multiple open official Chaos surfaces rather than relying on one CRMAX index:
1. Chaos technical documentation pages indexed under docs.chaos.com / documentation.chaos.com.
2. Chaos Help Center Corona for 3ds Max section.
3. Official feature/how-to/troubleshooting articles.
4. Current release-era articles where behavior changed.

Modules in this folder cover engine baseline, IR, materials, lighting/environment, LightMix, denoising, VFB/tone mapping, GI/performance, animation, network rendering, proxies/scatter, displacement, color management, caustics and troubleshooting.

When an exact parameter/UI path is version-sensitive, verify it against a current official page before asserting it.

## Version scope
Inherited software notes; only the selected claims in [compatibility and validation](compatibility-and-validation.md) were rechecked during v1.2 adaptation. Confirm version-specific features, compatibility, UI paths and numeric settings against official documentation matching the installed version before use.
