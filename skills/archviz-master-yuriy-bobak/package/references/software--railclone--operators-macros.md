# RailClone Operators & Macros

Operators modify segment behavior or parameter logic. Official categories include Arithmetic, Compose, Conditional, Link, Material, Mirror, Randomize, Reverse, Selector, Sequence, Tags, Transform and UVW XForm.

## ArchViz uses
Conditional/Selector: facade variants and design rules.
Sequence/Randomize: controlled module variation.
Transform/Mirror/Reverse: orientation and modular reuse.
Material/UVW XForm: material IDs and texture behavior.
Arithmetic/parameters: dimension-driven logic.
Tags: metadata/integration, including ForestPack geometry matching.

## Macros
Macros encapsulate subgraphs into reusable nodes. They can output numeric, geometry or generator behavior and can be saved/shared as .rcm files.

Create studio macros for repeated studio systems rather than rebuilding graphs per project.
