# RailClone Core

RailClone styles combine Segments, Generators, Base Objects, Parameters and Operators.

## Segments
Reusable scene objects/groups become building blocks. Segment controls include sizing, padding and alignment behavior.

## Base objects
Splines drive construction paths/boundaries in current core workflows.

## Style
The procedural graph defining how geometry is assembled. Editing base objects or parameters updates dependent geometry.

## ArchViz rule
Use RailClone when geometry is repeated, rule-based and revision-heavy. Use direct modeling for unique forms where a procedural graph adds complexity without reuse.

## Version scope
Inherited software notes; only the selected claims in [compatibility and validation](compatibility-and-validation.md) were rechecked during v1.2 adaptation. Confirm version-specific features, compatibility, UI paths and numeric settings against official documentation matching the installed version before use.
