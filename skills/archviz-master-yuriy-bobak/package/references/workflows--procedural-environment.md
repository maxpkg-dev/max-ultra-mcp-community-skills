# Procedural ArchViz Environment Workflow

1. Read drawings/site plan and identify repeated systems.
2. Separate systems into:
   - unique modeled architecture;
   - RailClone procedural architecture;
   - ForestPack scattered/environment assets.
3. Build clean splines/surfaces as control geometry.
4. Use RailClone for curbs, fences, facades, panels, railings and other rule-based repetition.
5. Use ForestPack for vegetation, grass, rocks, people/cars and dense repeated assets.
6. Where useful, export RailClone segment positions to ForestPack.
7. Art-direct density and variation based on camera, not randomness alone.
8. Protect roads, entrances, paths, facade features and sight lines with include/exclude areas.
9. Check foreground/middle/background density and detail hierarchy.
10. Optimize display/render behavior before final rendering.
11. Validate the result against the ArchViz Core: composition, depth, hierarchy, light and narrative.
