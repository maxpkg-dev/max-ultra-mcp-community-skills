# RailClone L1S

L1S creates one-dimensional arrays along a spline/path or numeric length.

Typical inputs/rules include Default, Start, End, Corner and Evenly spaced segments.

## ArchViz uses
- curbs;
- fences;
- railings;
- parapets;
- cornices;
- road-edge systems;
- facade trims;
- repeated lights/posts;
- street furniture.

## Workflow
Build clean spline → create modular segments → assign semantic slots → expose important numeric parameters → add controlled variation/operators → validate corners/start/end behavior.
