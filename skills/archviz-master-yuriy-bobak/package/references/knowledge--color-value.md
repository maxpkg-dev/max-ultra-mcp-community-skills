# Color & Value
## Value
Color cannot rescue a weak value structure. Check grayscale and simplified value groups.
Strong value contrast attracts attention. Background/distant regions often benefit from narrower contrast/value ranges.

## Color
Use saturation and temperature as hierarchy controls. With distance, colors generally lose saturation/contrast and may shift toward cooler/greyer atmospheric mixtures depending on conditions.

Do not blindly apply a warm-foreground/cool-background recipe; respect actual light and atmosphere.

## Diagnostic
Locate strongest contrast, saturation, highlight, dark and temperature accent. Check whether they support the intended focal point.


## Expanded book-grounded diagnosis

Source keys L, C and P and page-number conventions are defined in the [evidence register](book-evidence-register.md). ArchViz applications are production interpretations, not software instructions from the books.

### Preserve value groups while adding detail

L 20-21 introduces simplified value organization; L 269-270 and 282 return to protecting the large statement during detailed work. Three or five values are useful study choices, not a required tonal count for a finished render.

**ArchViz application:** compare the current render with a small grayscale version and an earlier blockout. Identify whether landscaping, facade joints or highlights have fragmented the building's main silhouette. Change the offending local contrast before increasing global contrast.

**Diagnostic:** can the intended building, entrance and surrounding landscape still be distinguished as a few meaningful masses? A deliberately quiet, low-contrast image can pass this test.

### Exposure is a choice about information

L 23-24 discusses the limited range available to an image; L 55-58 shows how exposure affects color distinctions and luminous appearances.

**ArchViz application:** decide which interior or exterior information is essential before adjusting exposure or compressing highlights. Recovering every window and every shadow is not automatically the best result. Preserve required product or architectural information, then judge the intended light impression.

### Color can add interest without breaking value structure

L 39-40 distinguishes chroma concepts from simple saturation controls. L 313, 316 and 332 shows selective color contrast and restraint.

**ArchViz application:** introduce hue differences within a stable value group when vegetation or facade detail needs richness without becoming a competing focal point. Avoid assuming that raising a saturation slider is equivalent to solving color hierarchy.
